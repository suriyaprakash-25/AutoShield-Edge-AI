# Hybrid-v4 demo parameter bundle

These JSON files contain the semantic parameters used by the Stage-2 Windows POC:
- the commissioned Hybrid-v4 allowlist/rate/DLC policy,
- the frozen RPM `0x316` Logistic Regression specialist,
- the frozen Gear `0x43F` Logistic Regression specialist.

The values were mirrored from the frozen Hybrid-v4 artifacts previously audited in the Nvidia/B200 development workspace.
The files are re-serialized for this demo bundle and are therefore not intended to be byte-for-byte hash-identical to the B200 copies.

The demo engine uses the same feature means, scales, coefficients, intercepts and frozen probability thresholds to produce ML evidence.
